# High-end product launch production

The working stack has distinct jobs: capture supplies product truth, composition supplies precise storytelling, spatial rendering explains relationships, and generation supplies selected illustrative shots. A model or template is not a guarantee of finished creative quality.

## Shot-to-tool routing

| Shot requirement | Route |
|---|---|
| Founder speaking | Real founder recording or a verified own avatar/voice; keep performance natural |
| Real product interaction | Authorized application capture using configured Playwright, Screen Studio, OBS or supplied footage |
| Exact interface highlights, typography and transitions | Remotion; Motion/GSAP for suitable authored UI/interactive use, with deterministic frame timing for offline output |
| Layered spatial UI | CSS perspective for simple panels; Three.js/R3F when true scene geometry is needed |
| Real map/parcel/terrain sequence | MapLibre/deck.gl/Cesium/Blender as appropriate, with sourced geometry and imagery attribution |
| Illustrative cinematic scene | A verified hosted video tool or a benchmarked open-model runtime |
| Timeline finishing, captions and localization | Connected Descript or an appropriate finishing editor |
| Sound mix, technical encoding and assembly | Descript/finishing editor plus FFmpeg utilities |

Use the new launch-film research and acquired-skill manifest for current sources, setup state and licence notes. Do not download every model; select one route per shot and expand only where a test shows a benefit.

## Project package

Retain a brief, source-backed script, timed storyboard, real product-capture plan, founder script, spatial-scene plan, reference frames, sound cue sheet, asset/provenance manifest and provider job ledger. Keep approved footage and references in private media storage. Exact palette, soundtrack, typography and timing are project decisions; template defaults are examples.

## Build and compare

1. Test a short real UI interaction for legibility and coherent cause/effect.
2. Test one founder-to-UI transition for identity, performance and compositing.
3. Test one spatial relationship for comprehension, stability and accurate labels.
4. Test sound against the same short edit rather than in isolation.
5. Compare to the creator's specified reference qualities: narrative clarity, real demonstration, natural founder presence, purposeful spatial motion, typography, transition quality, sound and final export quality.

Use the Remotion starter for typography/spatial-panel composition and supplied-media slots. Its synthetic demonstration is a technical foundation, not a real product walkthrough or a finished launch film. Include actual footage and apply a scene-specific edit before evaluating whether the result matches or exceeds a reference.

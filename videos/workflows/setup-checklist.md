# Readiness checklist

| Area | Ready means |
|---|---|
| Context | Creator and product facts have dated sources; approved preferences and unknowns are distinct |
| Character | Own avatar/voice selection verified in the chosen provider; pronunciation sample passes |
| Visual references | Exact reference links captured, and pacing/color/type/camera/sound preferences extracted |
| Brand assets | Correct logo, licensed fonts, palette and real product captures are available |
| Accounts | Provider connection, workspace and relevant capabilities checked in the current session |
| Local editing | Python, ffmpeg and ffprobe available; sample assembly/export verified |
| Open models | Selected checkpoint/version, terms and GPU runtime tested, if this route is needed |
| Storage | Private source/master location chosen; stable IDs and checksums recorded |
| Operations | Monthly volume, deadlines, spending limits and publication instructions recorded |

Unknown preferences need not block research, scripting or technical setup. They can block a faithful final avatar performance or a paid/public action. Do not ask the creator to reconfirm choices already recorded.

---
name: product-ui-demo
description: Prepare accurate, cinematic product demonstration footage for a launch film.
---

Define one complete interaction: input, action, visible response and useful result. Use the actual application or approved supplied capture. Prepare a clean demo account with non-sensitive fixtures and a reproducible starting state. Capture at enough resolution for the intended crop; preserve readable labels, cursor intent and time for comprehension. Record source URL/build/date, capture settings, the demonstrated feature and any simulated state in provenance.

Use an authorized connected browser when it is available for UI operation. Playwright is a programmatic capture option for a separately configured application/test environment; installing it does not connect the user's signed-in browser. Screen Studio or OBS can supply footage when capture is performed directly. Do not expose personal records or turn a designed UI mockup into purported product evidence.

Hand the selected footage, interaction timing, focal regions and framing needs to composition. Composite exact annotations after capture. A mockup can be useful for a clearly labelled vision/demo study, with its status retained in the project record.
